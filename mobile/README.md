# TALA Mobile

React Native 0.88.1, Community CLI 20.2.0. Android et iOS natifs, sans Expo. AppAuth et stockage Keychain.

Lancer `npm run dev` à la racine du dépôt. Ici, lancer `npm start`, puis `npm run android` dans un autre terminal avec JDK 17 et une cible ADB disponible. `npm run android:build` compile sans installer.

Validation : `npm run typecheck`, `npm run lint`, `npm test -- --runInBand`. iOS nécessite macOS/Xcode et les pods.

Voir [le guide complet](../docs/clients-web-mobile.md).
